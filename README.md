# POINT! Ultimate V3
เกมออนไลน์ 1-12 คน ฝึกการสื่อสาร What → Why → How

## Audio
- ไม่มี Background Music เพื่อไม่รบกวนสมาธิและการพูด
- ยังคง Sound Effects สำหรับเริ่มเกม, เปลี่ยนช่วง, เริ่มพูด, โหวต และประกาศผล

## Flow
1. อ่านโจทย์ 45 วินาที
2. ผู้เล่นแต่ละคนคิดส่วนตัว 30 วินาที พร้อม Timer
3. พูดภายใน 60 วินาที
4. ผู้เล่นอื่นโหวต

## Render
Build Command: npm install
