# POINT! Ultimate V2
เกมออนไลน์ 1-12 คน ฝึกการสื่อสารให้กระชับ โดยใช้แนวคิด What → Why → How แบบไม่บังคับสคริปต์

## Flow ใหม่
1. อ่านโจทย์พร้อมกัน 45 วินาที
2. เมื่อถึงคิวของผู้เล่นแต่ละคน มีเวลาคิดส่วนตัว 30 วินาที พร้อม Timer ใหญ่บนจอ
3. พูดด้วยคำของตัวเองภายใน 60 วินาที
4. ผู้เล่นอื่นโหวตความชัดเจน

โจทย์ถูกปรับให้เป็นภาษาไทยง่ายมาก อ่านแล้วเข้าใจสถานการณ์ทันที ไม่มีคำตอบ What/Why/How สำเร็จรูปบนหน้าจอ
