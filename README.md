# POINT! STORY CHAOS V4.1 Natural Thai Voice

Browser TTS voice selection improved:
1. Filter th-* voices first.
2. Prefer known Thai voice-name patterns when available: Premwadee, Niwat, Achara, Kanya, Google Thai.
3. Fall back to the device's default Thai voice, then any Thai-labelled voice.
4. Speech rate 0.88 and pitch 1.0 for clearer natural pacing.

Important: Web Speech voices come from the user's device/browser. The exact voice available can differ across Windows, macOS, Android, iOS, Chrome, and Edge.
