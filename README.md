# POINT! STORY CHAOS V2
เพิ่ม Live Emoji, Soundboard แบบ real-time, cooldown 1.8 วินาที และตรวจ Keyword อัตโนมัติจาก Speech Recognition ภาษาไทย

แนะนำ Chrome หรือ Edge และต้องอนุญาตไมโครโฟน การตรวจเป็นการจับคำจาก transcript จึงขึ้นกับความชัดของเสียงและ Browser

Render: Build `npm install` / Start `npm start`
