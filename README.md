# POINT! STORY CHAOS V5 - Improved What Why How Logic

Bot framework revised:
- WHAT = only the key point / decision / issue the listener needs first.
- WHY = why the issue matters and why it needs attention now.
- HOW = supporting details: when/context, impact, choices/options, and recommended next step.
- All three parts are generated as one coherent story using the same 4 keywords.
- Bot TTS still uses browser JavaScript SpeechSynthesis. No Azure Speech-to-Text or Azure TTS is required.
- Visual WHAT / WHY / HOW labels remain for learning, but TTS reads only the connected story text.

Existing V4.1 features remain, including multiplayer scoring, 50/50 keyword and peer rating, live reactions, soundboard, bots, and JavaScript speech recognition for keyword checking.
